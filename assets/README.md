# Assets Folder

Place your media files here:

```
assets/
├── images/      ← Photos, banners, team images, logos (PNG/JPG/WebP)
├── icons/       ← Custom SVG icons or favicon files
└── README.md    ← This file
```

## Recommended Files to Add
- `images/logo.svg` — Vector INOVASS logo
- `images/hero-bg.jpg` — Optional hero background photo
- `images/map-indonesia.svg` — Indonesia map illustration
- `images/partner-*.png` — Partner/client logo images
- `icons/favicon.ico` — Browser favicon
- `icons/favicon-32x32.png` — Standard favicon
- `icons/apple-touch-icon.png` — iOS home screen icon
